                Where every number comes from

                  The Herald is written by a script from files OLYMPUS already publishes. It invents nothing: every number in a story is read from a named file, and a story whose file is missing is not written. It never trades and never moves money; paper and suggestions only. A DEMO or sample mark means example data. Savings in the classifieds are estimates, not promises.
